# Waymo Data Validator

## Overview

This project simulates a data validation tool used in autonomous vehicle operations.

It checks annotation records for missing labels, invalid confidence scores, duplicate IDs, and generates a quality report.

## Features

- Validate annotation records
- Detect missing labels
- Detect duplicate IDs
- Verify confidence scores
- Generate summary statistics

## Technologies

- Python

## Future Improvements

- CSV file support
- Dashboard visualization
- Automatic report generation
